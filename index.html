☁️ Git 云同步

⚠️「恢复」会用云端数据完全替换本地，本地未推送的数据将丢失

开启后：停用自动云同步与全部同步弹窗，数据只保存在本机浏览器（关机/重启后照常使用、不丢失）；手动「推送/拉取」仍可用，想上云随时点。

本仓库是公开的，未加密时 data.json 任何人可下载（含学生姓名与家长电话）。
开启同步口令后，上传的是 AES-256 密文，公开也无所谓；每台设备须设成完全相同的口令。

🔒 修改登录密码

密码经哈希加密存储，请妥善保管

📋 跨电脑使用指南

步骤 1：在当前电脑点击「💾 导出数据」，会下载一个 班级名_YYYY-MM-DD.json 文件

步骤 2：将此文件通过 U盘 / 微信文件传输 / 网盘 等方式传到另一台电脑

步骤 3：在另一台电脑打开本系统，点击「📂 导入数据」选择该文件即可恢复全部数据

💡 提示：也可以直接把 index.html 和 json 数据文件一起放进U盘的网页文件夹，到任何电脑双击打开即可使用。

· 新增「📴 纯本地模式」：设置页一键停用自动云同步与全部同步弹窗，数据只存本机、关机重启不丢失；手动推送/拉取仍可用（v2.18.11）
· 修复平板/矮窗口下侧栏导航「设置」显示不全且无法滑动：导航列表允许收缩内部滚动，视口高度改用动态单位 dvh（v2.18.10）
· 修复：往新建大类里添加原因后刷新整组消失——隐式新建大类/方向时同步清除其旧删除记录（v2.18.8 时间戳仲裁的补漏）
· 修复：重新添加的原因/大类刷新后被云端旧删除记录整体抹掉——删除与重新添加改按时间戳仲裁，重新添加晚于删除则旧记录作废
· 云同步推送失败自动重试并改用中文提示：网络抖动/并发冲突自动退避重试，Token 失效/口令不一致等会明确告诉你原因
· 修复：编辑课堂纪律原因分值后切页面/刷新偶发被云端旧值复原——原因分值合并改为本地优先，未推送的编辑不再被覆盖
· 座次表支持拖拽换座：按住座位卡片拖动即可换座——拖到已占座位两人互换、拖到空位直接移动（触屏长按约 0.2 秒后拖动）
· 三个排座按钮改为「只填空座」：先手动排好的座位一律保留，未入座学生按所选顺序（学分高→低 / 姓名 / 随机）从前往后依次补位
· 原生弹窗全部换成站内模态（新增 / 重命名方向与大类、改班级口号、续假日期），重置口令改用密码框输入、不再明文回显
· 修复原因目录改名不跨设备传播：改名后旧名记入删除墓碑，其他设备不会再同时出现新旧两份
· 代码清理与加固：删除 8 个零引用函数与 22 条无引用 CSS 规则；调试日志默认静默（地址栏加 ?debug=1 打开）
· 修复：处分记录此前不参与云同步，换电脑 / 清缓存后从云端恢复会全部丢失（现已打通上传与合并）
· 新增「🔁 重置云端加密口令」：改口令后一键用新口令重推云端，无需手动删除云端文件
· 工作记录补上关键词搜索框（跨日期检索标题与内容），此前过滤逻辑一直空转
· 本地存储写满时不再静默失败，会明确提示并照常推送云端
· 零扣分榜改为按「未扣分天数」排名（右侧直接显示天数 / 从未扣分），不再与学分挂钩
