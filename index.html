☁️ Git 云同步

开启后：停用自动云同步与全部同步弹窗，数据只保存在本机浏览器（关机/重启后照常使用、不丢失）；手动「推送/拉取」仍可用，想上云随时点。

数据存于私有仓库（外部访客访问一律返回 404），每台设备须配置对该仓库有读写权限的 GitHub Token 才能同步。
上传的是 AES-256 密文，云端只留密文；每台设备须设成完全相同的同步口令。

🔒 修改登录密码

密码经哈希加密存储，请妥善保管

📋 跨电脑使用指南

推荐：云端同步（免搬运）——新设备打开同一网址并登录后：①「☁️ Git 云同步」→「配置 GitHub Token」（对该私有数据仓有读写权限）；②「配置同步口令」（须与其他设备完全相同）；③ 点「⬇️ 从云端拉取数据」，数据自动解密合并到本机。

注意：若开启了「登录密码仅限本机」，新设备首次登录需输入管理员密码授权一次。

💡 备用方案：完全离线的环境才用「💾 导出数据」导出 JSON 文件、拷到新设备后「📂 导入数据」恢复（导入前旧数据会自动备份）。日常换电脑请优先走云同步，避免数据版本落后。

⚠️ 危险操作

「从云端恢复」会用云端数据完全替换本地，本地未推送的数据将丢失；「清空数据」清空本机全部数据，并同步清空云端（其他设备打开时会自动对齐清空，旧数据不会复活）。
两项均有二次确认；执行前建议先「💾 导出数据」留一份备份。

· 📝 更新速览默认收起：本节改为折叠式，点标题展开，不再占据半屏
· ⚠️ 危险操作聚合：「清空数据」「从云端恢复（覆盖本地）」集中到独立的「危险操作」区并统一警示样式，「重置云端加密口令」同步改为警示配色；三项均有二次确认 · 📱 手机端两个修复：① 请假条不用再左右滑 —— 有「续假」历史的记录会把卡片撑得比屏幕还宽、整页跟着横向滚动，现在超长历史自动省略号收尾，卡片始终贴合屏幕宽度；② 切模块回主页能看见课程表了 —— 从往下翻过的长页面（请假 / 德育 / 座位）点回「首页」时不再停在上一页的滚动位置，回首页即从头开始，最上面的课程表直接可见

· 🚫 关闭座位防误触：退出「关闭座位模式」后，座次表顶端的提示条不再一直挂着；已关闭的格子也不会再「点一下就打开」—— 不管关还是开，都要先进「🚫 关闭座位」模式再点格子
· 👥 值日不再有 2 人小组：一组改成 3—4 人 —— 先按 4 人切满，末尾不足 3 人时与前面几组重新均分（一组仍是「一周教室 + 一周公卫」的同一批人）。本班 58 人 → 13 组 4 人 + 2 组 3 人，仍是 15 组一轮
· 🔁 值日按轮值表重做：每周教室 1 组 + 公共卫生 1 组，按组数循环，和班里的轮值表逐格对得上
· 🔴 一键罚扫 / 延缓：本周两个岗位上各有两个按钮 ——「🔴 下周继续罚扫」让这组下周再做一次（只作记录，不自动扣分）；「⏸ 延缓一周」让这周该岗位轮空、这组和后面全体顺延一周（方便插入别的罚扫组）。两者都只动它那一个岗位，教室罚扫不影响公卫轮值
· ↶ 改错了能退：工具栏「↶ 撤销上一步」逐步回退，「🧹 恢复正常轮值」一键清空全部罚扫与延缓，回到原始循环
· 🖼️ 导出图改成轮值表：导出的图片现在是「周次 × 教室卫生 × 公共卫生」的整张表，周几谁扫一目了然，打印出来直接贴墙
· 🎲 值日可随机分组：值日排表页把「重新分组」拆成两个按钮，一键「🎲 随机分组」把全班打乱后重新切小组，想恢复整齐就用旁边的「按学号分组」
